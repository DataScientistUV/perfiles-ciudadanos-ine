# Base de datos

`INE_BASES_COMPRIMIDAS.zip` (39.4 MB) contiene los Conteos Censales de Participación Ciudadana del INE de las elecciones federales de 2009 a 2024, con un ZIP por elección.

Se descarga desde la sección Releases de este repositorio:
https://github.com/DataScientistUV/perfiles-ciudadanos-ine/releases/download/datos/INE_BASES_COMPRIMIDAS.zip

Para ejecutar el código, guarda el archivo sin descomprimir en tu Google Drive, en Mi unidad. Al iniciar, Colab pide permiso para conectarse a Drive.
